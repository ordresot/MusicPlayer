---

## Reporting a Vulnerability

We take the security and privacy of Void Player users seriously. Void Player is designed to operate 100% offline with zero remote telemetry or user tracking.

If you discover a security vulnerability or privacy concern in Void Player, please report it responsibly:

1. **Do not disclose publicly**: Avoid opening a public GitHub issue immediately for sensitive security vulnerabilities.
2. **Contact**: Open a private security advisory on GitHub via the [Security Advisories](https://github.com/TUSHAR91316/Void-Player/security/advisories/new) tab, or reach out directly to the maintainer.
3. **Include details**:
   - Description of the vulnerability.
   - Steps or proof-of-concept to reproduce the issue.
   - Potential impact and affected platforms (Android / Desktop).

We will investigate all reports promptly, provide updates, and release a patch as quickly as possible.
